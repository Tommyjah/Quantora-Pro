# 🏹 Quantora Pro

### *AI-Powered Quantitative Stock Signals & Market Intelligence*

Quantora Pro is a modern, high-performance financial technology dashboard that processes live market data pipelines, runs algorithmic technical indicators, and leverages advanced AI multi-agent orchestrations to deliver institutional-grade trading briefs.

![Quantora Pro Logo](IMG_20260514_170127_820.jpg)

## ⚡ Core Features
* **Live Market Synchronization:** Real-time data routing via Alpha Vantage API.
* **Algorithmic Engine:** Structural trend tracking using 10-Day and 30-Day Moving Average crossovers.
* **AI Deep Intelligence Core:** Contextual, ultra-dense executive briefs generated by automated CrewAI specialists powered by Groq (LLaMA-3.3).
* **Multi-Channel Dispatch Pipeline:** Parallel signal routing that delivers immediate trade alerts straight to custom Telegram endpoints and Email inboxes.
* **SaaS-Branded Interface:** Responsive Bento Box layout and interactive vector trend graphs powered by Streamlit and Plotly.

## 🛠️ Tech Stack
* **Frontend & UI:** Streamlit, CSS Injection
* **Data & Analytics:** Pandas, Plotly, Requests
* **AI Framework:** CrewAI, Groq (LLaMA-3.3-70b)
* **Alert Routing:** SMTP Secure Protocol, Telegram Bot API
